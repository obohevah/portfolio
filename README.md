# Evah Oboh - Professional Portfolio Website

Modern, executive responsive portfolio website for **Evah Oboh** (Full-Stack Web & Mobile App Developer at SparkWeb Tech Limited).

### Live Website
- **Live URL:** [webmast.name.ng/portfolio2](https://webmast.name.ng/portfolio2)

### Features
- **Responsive Layout:** Strict mobile-first 12-column grid system built with Bootstrap 5 and custom CSS.
- **Dynamic Typewriter:** Interactive role cycling highlighting full-stack, mobile app, and payment integrations.
- **Project Showcase:** Filterable gallery featuring authentic web applications and systems.
- **Direct Lead Conversion:** Integrated AJAX contact form handler and floating WhatsApp direct messaging.
- **Cross-Browser Compatibility:** Tested and optimized for modern desktop, tablet, and mobile browsers.

### Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, FontAwesome
- **Backend:** PHP 8.2 (AJAX form handler, PHPMailer integration)
- **Deployment:** Apache, cPanel, SSL
